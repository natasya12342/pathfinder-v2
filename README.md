# PathFinder — Eksplorasi Jurusan, Minat & Jalur Karier

Aplikasi web edukatif interaktif dan penuh warna untuk membantu siswa memahami konsep pemilihan jurusan, perbedaan minat dan kemampuan, serta memetakan kecenderungan ke dalam 4 klaster utama:
1. **Logika & Sistem**
2. **Analisis Data & Riset**
3. **Komunikasi & Sosial**
4. **Bisnis & Ekonomi**

## Fitur Utama
- **Panduan Awal Edukatif:** Membahas penjurusan, perbedaan minat vs. kemampuan, salah kaprah umum, serta pengenalan 4 klaster sebelum masuk ke soal.
- **Kuis Interaktif 8 Soal:** Dilengkapi petunjuk singkat tiap soal, validasi jawaban, dan navigasi maju/mundur.
- **Hasil Analisis Real-Time:** Menampilkan skor & persentase tiap klaster dengan warna berbeda, rekomendasi jurusan & karier, serta *roadmap* langkah awal (0–6 bulan).

## Cara Mengakses & Menjalankan
- Buka tautan GitHub Pages proyek setelah diaktifkan pada menu **Settings > Pages** (`branch: main`, folder `/ (root)`).
- Dapat diakses melalui browser HP, tablet, laptop, maupun PC.

## Catatan Keamanan & Data Simulasi
- Seluruh data bersifat simulasi untuk tujuan pembelajaran dan demonstrasi.
- Tidak menyimpan data pribadi pengguna serta tidak menggunakan *API key* atau kredensial rahasia.
